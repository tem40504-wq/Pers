# GameScreen Voice 0.1.2 — Android Studio SOURCE MVP

**Статус:** исходники исправлены относительно 0.1.1. См. `CHANGELOG_0.1.2_RU.md`. 31 статическая проверка проходит (`python tests/static_check.py`), но они не гарантируют успешную сборку. APK не собран и не протестирован на реальном Android: в рабочей среде нет Android SDK и установленного Gradle. Возможны ошибки совместимости, выявляемые при первой Gradle Sync.

### Стек
Kotlin 2.3.21 / AGP 8.9.2 / Gradle 8.11.1 / Jetpack Compose / minSdk29 / compileSdk35 / targetSdk35 / Room / Retrofit / OkHttp / Android Keystore / Android TextToSpeech / AccessibilityService / foreground specialUse WindowManager overlay.

### Сборка на Windows
1. Установите Android Studio, Android SDK Platform 35, Build Tools 35.0.0, JDK 17.
2. Распакуйте проект. Для автоматической сборки запустите `BUILD_WINDOWS.bat` — скрипт загрузит **официальный Gradle 8.11.1**, проверит SHA256, при необходимости создаст `local.properties` с путём к SDK, затем соберёт debug APK. Требуются интернет и установленный SDK API 35. Скрипт не устанавливает Android SDK.
3. Альтернативно откройте папку в Android Studio. При наличии установленного Gradle выполните `gradle wrapper --gradle-version 8.11.1`, после чего `gradlew.bat :app:assembleDebug`. В архиве нет бинарного `gradle-wrapper.jar`.
4. Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
5. Установите на Android 10–15.

### Первый запуск
1. На экране приложения прочитайте уведомление и отметьте согласие.
2. Нажмите «Выбрать из установленных приложений» (или впишите package вручную) — без него сбор текста отключен. Для проверки перевода есть отдельная кнопка «Тест».
3. Введите собственный DeepL API key. Free или Pro определяется автоматически (ключи Free оканчиваются на `:fx`). Поле «Из» можно оставить пустым — DeepL определит язык сам. Ключ автоматически сохраняется при нажатии «Тест» или «Запустить»; отдельная кнопка «Сохранить настройки» тоже работает. Секрет шифруется при хранении через Android Keystore.
4. Откройте системные настройки Accessibility через кнопку и вручную включите GameScreen Voice.
5. Разрешите overlay, затем нажмите «Запустить».
6. Откройте указанный пакет: его видимый доступный для Accessibility текст будет переведен и показан в окне.
7. При необходимости нажмите «Озвучить» (язык голоса должен быть установлен в Android TTS). «Стоп» внутри окна останавливает TTS, «×» или уведомление останавливают сервис.
8. Поменяв размер/непрозрачность окна, нажмите «Запустить» ещё раз — параметры применятся без перезапуска.

### Ограничения и приватность
- Текст игр, отрисованный в Vulkan/OpenGL/Unity/Unreal, обычно не доступен Accessibility. OCR — фаза 2.
- В MVP нет OCR, микрофона, захвата звука, распознавания речи, фоновой автоозвучки, переключения провайдера через UI и облачного TTS. Для будущего переключения провайдера предусмотрен интерфейс `TranslationRepository`.
- API-ключ хранится на телефоне шифрованным, но при вызове DeepL в мобильном приложении извлекается в память и используется напрямую. Для многопользовательского коммерческого приложения необходим backend proxy, квоты и abuse protection. BuildConfig не защищает секреты.
- Режим хранения истории по умолчанию выключен. Если включить — переведенные строки сохраняются в локальном Room. Историю можно удалить на экране настроек.
- Доступ ограничен одним явно указанным пакетом, поля пароля/редактируемые поля игнорируются, свои оверлеи не читаются. Для Google Play потребуется корректная декларация Accessibility, демонстрация и текст приватности.
- Google Play с 31.08.2026 требует targetSdk 36 для новых приложений и обновлений. Здесь targetSdk35 сохранён строго по запросу: годится для локальных тестов/sideload, но не для новой публикации без допустимого продления.

### Исправления 0.1.2
- Сборка: `kotlinOptions` (ошибка в Kotlin 2.2+) заменён на `compilerOptions`; скрипт сборки создаёт `local.properties`.
- Нет падения сервиса без разрешения overlay; тёмная тема и Android 15 edge-to-edge отображаются корректно.
- Перевод не «залипает» после ошибки и не откладывается бесконечно на постоянно меняющемся UI; Accessibility получает события только от выбранного пакета.
- Автовыбор DeepL Free/Pro, автоопределение исходного языка, выбор приложения из списка, индикаторы разрешений.

### Исправления 0.1.1
- Демоперевод работает без запуска сервиса и доступов к экрану.
- Изменения настроек применяются при «Запустить» даже без предварительного нажатия «Сохранить».
- Исправлено ограничение `startForeground(specialUse)` на Android 10–13 и visibility для TTS-движков на Android 11+.
- Добавлены debounce чтения Accessibility и перепроверка пакета активного окна, временный RAM-кэш, обработка кодов ошибок DeepL и ограничение перемещения окна.

### Проверки
1. Разрешения выключены: сервис не должен захватывать содержимое.
2. Запуск без Overlay permission: выводится ошибка, FGS не запускается.
3. Тестовый текст «Hello world»: запрос DeepL, результат и озвучивание.
4. Выбор пакета A: пакет B игнорируется.
5. Быстрая смена текста: устаревшие переводы не должны заменять новые; при постоянно меняющемся UI перевод всё равно появляется (≤ задержка + 1,5 с).
5a. Выключить сеть → ошибка; включить → тот же текст переводится повторно в течение ~5 с.
6. Системный TTS не установлен / нет русского голоса: корректная ошибка при озвучивании.
7. Проверить Android 10/11/12/13/14/15, в том числе выключение/включение экрана, управление кнопками под окном и уведомление.
8. По возможности измерять FPS, нагрузку CPU и энергопотребление на реальном устройстве; обещать отсутствие просадки без тестов нельзя.

### Структура
- `capture/GameAccessibilityService.kt` — извлечение текста Accessibility
- `domain/TranslationRepository.kt` — контракт провайдера
- `data/DeepLTranslationRepository.kt` — API
- `domain/TranslationPipeline.kt` — Flow, отмена устаревших операций, опциональная история
- `platform/OverlayService.kt` — foreground overlay, перетаскивание и копирование
- `platform/TTSManager.kt` — Android TTS
- `data/HistoryDatabase.kt` — Room
- `data/SecretStore.kt` — Keystore
- `ui/MainActivity.kt` / `ui/MainViewModel.kt` — настройки Compose и MVVM
- `phase2_samples` — примеры OCR/STT/захвата аудио, не собранные в MVP.
