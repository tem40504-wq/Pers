# GameScreen Voice Android 0.1.3

- **Перевод без ключа.** Если ключ DeepL не указан, текст переводится прямо на телефоне через Google ML Kit — бесплатно, без регистрации. При первом переводе загружается языковая модель (~30 МБ, нужен интернет и сервисы Google Play), дальше работает офлайн. Пустое поле «Из» — язык определяется автоматически.
- С ключом DeepL используется DeepL; переключатель «Всегда офлайн-перевод» принудительно включает ML Kit. Рядом со статусом видно, кто перевёл («Готово · офлайн» / «Готово · DeepL»).
- Кнопка «Запустить» больше не требует ключ DeepL.
- Постоянный debug-ключ подписи (`app/debug.keystore`): следующие версии устанавливаются поверх без удаления. **Версию 0.1.2 нужно один раз удалить** — она была подписана другим ключом.
- Kotlin 2.2.21 (Room 2.7.1 не поддерживает метаданные Kotlin 2.3).
- В APK только библиотеки для телефонов (arm64-v8a, armeabi-v7a).
- Сборка: GitHub Actions `.github/workflows/build-apk.yml` (ветка `build-apk`), BUILD SUCCESSFUL. На реальном устройстве не тестировалась.
