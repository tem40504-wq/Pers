UNIVERSAL GAME AGENT — LEVEL 5+

1. На Windows распакуйте ZIP с помощью «Извлечь всё».
2. Подключите телефон по USB и вручную включите отладку USB.
3. В папке проекта запустите START_L5_SAFE.cmd двойным нажатием.
4. Согласие на нужный пакет/изменение: прочтите причину, пользу и риски.
   Y = одноразовое разрешение, N = отказ + отключение функции или остановка.
5. Без --execute агент не нажимает в игре.
6. Панель оператора (если включена): http://127.0.0.1:8765
   PANIC STOP остановит новые команды, но не гарантирует отмену уже отправленного жеста.

Проверка только зависимостей: py main_l5.py --preflight-only
В реальной игре сначала: py main_l5.py --max-steps 5 --dashboard
После теста: py main_l5.py --max-steps 20 --dashboard --execute

Если приложение не работает, снимок окна ошибки пришлите для диагностики.
Полная инструкция в README.md. Ни один из новых модулей не гарантирует победу
в любой игре; обучение требует данных, калибровки и проверки на устройстве.
