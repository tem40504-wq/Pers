# Universal Game Agent Level 6 — установка и проверка

**Это исходный проект для Windows и телефона по USB, не APK.**

## Что изменено
- Новые `game_agent/l6/*.py`; прежние версии сохранены.
- Небольшой hook в `game_agent/l5/agent_l5.py` для подтверждённого опыта.
- `main_l6.py` и `START_L6_SAFE.cmd` — новый, безопасный по умолчанию, запуск.
- Внутри L6 нет автоматических `pip install`, загрузки весов, подключения к серверам.

## Тесты
```
py -m pytest -q tests
```

## Проверка без телефона
```
py main_l6.py --preflight-only
```
Команда только проверяет зависимости и через существующий PermissionGate спрашивает о недостающих компонентах. Не использует USB и не нажимает кнопки.

## Тестовое подключение
1. Включить Отладку по USB на Samsung и авторизовать свой ПК.
2. Подключить кабель передачи данных.
3. Распаковать ZIP полностью, открыть распакованную папку.
4. Дважды щёлкнуть `START_L6_SAFE.cmd`.
5. Скрипт выполняет ограниченный dry-run: 5 итераций без нажатий.

После проверки ручной запуск:
```
py main_l6.py --max-steps 5
```
Для реальных команд (только на разрешённом тестовом стенде):
```
py main_l6.py --execute --max-steps 20
```

## Федеративный обмен
По умолчанию сеть полностью выключена. Для своей инфраструктуры подготовить HTTPS relay, ключ HMAC длиной от 32 случайных байт, вызвать `FederatedHub.exchange(..., gate=PermissionGate())`. Каждый исходящий обмен требует подтверждения Y/N. Никогда не публиковать локальный пример `examples/federated_relay.py` в Интернет напрямую.

## Синтез инструментов
Инструменты проходят AST-фильтр и тесты. Они могут возвращать только вычисленные данные и **не получают права** на управление устройством. Для общего Python нужен отдельный контейнер с системной изоляцией, которого в версии 6.0 нет. Активация после Y/N.

## Базовые ограничения
Experience Replay — не дообученная нейросеть. PyTorch веса можно *сохранить как доверенный snapshot*, но класс не обучает их без отдельно подключённого и проверенного trainer. Физика требует калибровки. AffectiveEngine не измеряет стресс оператора и не записывает речь.
