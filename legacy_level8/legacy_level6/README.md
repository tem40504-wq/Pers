# Universal Game Agent v5.0 — автономное обучение + объяснения оператору

Добавление Level 5 поверх **существующего** Level 4.1 PermissionGate.

## Комплектация

- `main.py` — прежняя версия L3, **без изменений**.
- `main_l4.py` — прежняя версия L4.1, **без изменений**.
- `main_l5.py` — новая версия с `WorldModel`, `AudioPerception`, `MetaAdapter`, `OperatorAssistant`, `XAI_Dashboard`, `PanicExecutor`.
- `game_agent/l5/` — новые модули (полный код с комментариями на русском).
- `PATCH_LEVEL4_TO_LEVEL5.diff` — минимальное изменение исходных L4-файлов.
- `START_L5_SAFE.cmd` — безопасный запуск на Windows.

Никакого автоматического изменения системных настроек или установки без явного `Y`. Отсутствие необязательных компонентов приводит к fallback (без новых функций), а не скрытой загрузке.

## Старт на Windows

1. Распаковать ZIP **через «Извлечь всё»**, не запускать CMD внутри ZIP.
2. На Samsung вручную включить отладку USB; подтвердить авторизацию своему ПК.
3. Дважды нажать `START_L5_SAFE.cmd`.
4. Если Python не установлен, поставить его вручную с https://python.org (программа этого не делает).
5. При отсутствии нужных библиотек консоль покажет название, действие, техническую причину, пользу и риски. `Y` — разовое согласие; `N` — отказаться.
6. При установленном FastAPI панель будет доступна только по `http://127.0.0.1:8765`.

### Команды

```powershell
# Только проверить зависимости; телефон не используется
py main_l5.py --preflight-only

# 5 шагов без касаний по телефону
py main_l5.py --dashboard --max-steps 5

# После тестов — разрешить до 20 реальных шагов
py main_l5.py --dashboard --max-steps 20 --execute

# OCR и семантическая память (при отсутствии пакета программа попросит Y/N)
py main_l5.py --dashboard --ocr --chroma --max-steps 5
```

### Безопасная работа с аудио

Аудио **по умолчанию выключено**. Телефон не обязан поддерживать ADB-audio. Для разрешённого звукового входа ПК нужны совместимые локальные веса и верифицированная карта меток:

```powershell
py main_l5.py --dashboard --audio-device 3 --audio-model .\models\my_audio_model.tflite --audio-map .\models\my_verified_mapping.json
```

Не используйте `examples/audio_class_map.example.json` в качестве реальной карты — цифры заглушечные. Программа запросит отдельное разрешение на аудиозахват. На Windows `tflite-runtime` может отсутствовать для вашей версии Python; в этом случае аудио остаётся отключённым без установки неизвестных исполняемых файлов.

### Обучение WorldModel

WorldModel обновляется только при фактически выполненных командах и доступной числовой телеметрии. Для HP/MP в новых играх надо настроить `--hp-roi` и `--mp-roi` или гарантировать корректные OCR-метрики. При отсутствующих метриках агент использует Level 4.

### Учебные подсказки оператору

Панель показывает изображение с bounding boxes, принятые решения, переписку роя и журнал безопасности. Уровень объяснений 0..3 переключается в браузере или текстовой командой `уровень 2`. Вопрос: `Почему не используешь ульту?`. Коррекция: `Не пей зелье, беги!`. В этом случае выполняется безопасное ожидание, если корректный навык отступления неизвестен.

Кнопка **PANIC STOP** блокирует последующие команды и останавливает цикл после текущего шага. На уже начавшийся USB-жест мгновенная отмена не распространяется.

## Проверка без смартфона

```powershell
py -m pytest -q
```

Тесты имитируют данные и устройства; они не подтверждают точность модели на настоящих игровых сценах или работоспособность конкретной аудио-модели.

## Ограничения

- DreamerV3 не входит; основная WorldModel — осторожная эмпирическая модель переходов.
- `rssm.py` — опциональная GRU RSSM-lite с самостоятельным обучением и валидацией; PyTorch не устанавливается автоматически.
- `MetaAdapter` — прототипная few-shot адаптация цвета, не MAML; 5–10 примеров должны быть размечены человеком.
- GAN — только исследовательский offline UX компонент. Никакой гарантии неотличимости от человека или обхода античитов.
- 2–3 минуты адаптации, 0.5-сек цикл и 30 FPS видео не гарантируются.
- Гарантированная аппаратная panic-stop требует аппаратного устройства; программный флаг перехватывает новые действия.

Читайте `ARCHITECTURE.md` для маршрута интеграции, ограничений и оценок задержек.
