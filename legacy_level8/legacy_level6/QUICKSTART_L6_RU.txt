Universal Game Agent v6.0 — быстрый запуск на ПК (Windows)

1. Полностью распакуй ZIP на компьютер; не запускай .cmd прямо из архива.
2. Если игра идёт на Samsung: включи отладку по USB, подключи телефон и подтверди разрешение.
3. В распакованной папке дважды нажми START_L6_SAFE.cmd.
4. Если потребуется установка пакета, PermissionGate покажет причину, пользу, риски и вопрос Y/N.
5. Первый запуск: 5 циклов, режим DRY-RUN, без реальных нажатий.
6. В случае ошибки пришли снимок окна запуска и лог (без ключей/API-токенов).

Для только проверки библиотек без телефона:
  py main_l6.py --preflight-only

Для тестов, если pytest уже установлен:
  py -m pytest -q tests

По умолчанию никакой синхронизации между ПК и генерации исполняемого кода нет.
Старые main.py, main_l4.py и main_l5.py работают отдельно.
