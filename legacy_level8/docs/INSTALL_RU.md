# Пошаговая установка Android + Termux + PC (Windows/Linux)

## Что необходимо заранее

- Android-телефон (например, Samsung Galaxy S22 Ultra). Современная версия Android, работающий Wi-Fi.
- Компьютер с Android Studio нужен **один раз для сборки Android Companion APK**. Сам агент выполняется на телефоне.
- Приложение Termux из проверенного проекта (F-Droid или официальный проект Termux), ставится **вручную** после ознакомления с его разрешениями. Не используйте случайные APK.
- Установка Python/библиотек/Gradle dependencies **только после явного решения пользователя**. Скрипты этого архива сами ничего не устанавливают.

## Этап A. Создание Android Companion APK

1. Распакуйте архив и откройте `android_companion/` в Android Studio на ПК.
2. Проверьте содержимое `AndroidManifest.xml`: INTERNET для local loopback, Accessibility Service, Foreground Service MediaProjection. Доступ к контактам, файлам, микрофону не запрашивается.
3. Android Studio может запросить загрузку Android SDK/Gradle — подтвердите отдельно. Проект требует компиляцию SDK 35 и Java 17, зависимости Gradle + ML Kit OCR. Без подтверждения не начинайте загрузку.
4. Соберите через **Build → Build APK(s)**, проверьте отладочный APK и установите его вручную на **свой** телефон. Этот архив содержит исходники Android, а не уже собранный APK.
5. На Samsung: Настройки → Специальные возможности → Установленные приложения → Game Agent Companion → Включить. Это очень сильное разрешение: предоставляйте его только своему проверенному приложению.
6. Откройте Companion → «Разрешить захват экрана». Система покажет отдельный диалог MediaProjection. При каждой новой сессии разрешение выдаётся заново.
7. В окне Companion появится `GAME_BRIDGE_TOKEN`. Он хранится только в памяти Android-процесса, при перезапуске меняется.
8. **На первом тесте не нажимайте ARM.** Проверьте соединение и скриншоты. Для реальных действий введите координаты **безопасной области** и нажмите `ARM` (ограничение 5 минут). `PANIC STOP` доступен в приложении и уведомлении.

## Этап B. Запуск Termux

1. Скопируйте папку с `mobile_core/`, `examples/` и `docs/` в приватный каталог Termux (`~/GameAgent`). Не размещайте токены в общем `/sdcard`.
2. Если Python отсутствует: откройте Termux и по собственному решению выполните `pkg update` и `pkg install python`. Автоматически эти команды агент не вызывает.
3. Запустите: `cd ~/GameAgent`.
4. Введите токен без публикации в сети, например `export GAME_BRIDGE_TOKEN='значение_с_экрана_Companion'`.
5. Сначала проверка без касаний: `python -m mobile_core.main_mobile --steps 5`.
6. Для работы с допуском safe-zone: `python -m mobile_core.main_mobile --execute --safe-box 100,300,700,1300 --steps 20`. Координаты в примере фиктивные; реальные выбирайте по игре. Потребуется Y в Termux И ARM в Companion. Если ни один детектор не определяет проверенную кнопку, безопасное поведение — `wait`.
7. 5-минутная проверка присутствия обязательна: ARM нужно обновлять **физически на телефоне**. Не пытайтесь обходить этот таймер программно.
8. Входные веса YOLO, YAMNet и SmolVLM не включены. Для них нужна отдельная ручная установка/проверка совместимости, калибровка и согласие. Автоматическая загрузка запрещена.

## Этап C. ПК и ADB over Wi-Fi (только отладка)

**ADB не нужен для автономной игры**, но полезен для безопасного мониторинга и переноса файлов.

1. ПК и Samsung должны быть в одной доверенной Wi-Fi сети. Установите официальные [SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) с согласия владельца.
2. На Samsung откройте **Настройки → Параметры разработчика → Беспроводная отладка**. Включите на время работы.
3. Нажмите **Подключить устройство с помощью кода сопряжения**. Телефон покажет `IP:PAIR_PORT` и код.
4. На ПК: `adb pair 192.168.1.50:PAIR_PORT` — используйте реальное значение. Введите код, отображённый на телефоне.
5. Вернитесь на основную страницу «Беспроводная отладка» и найдите **другой порт подключения** `IP:CONNECT_PORT`. На ПК: `adb connect 192.168.1.50:CONNECT_PORT`. Затем `adb devices`.
6. Для мониторинга Termux сервера (который сначала нужно запустить с отдельным Y): `adb forward tcp:8765 tcp:8765`. ПК обращается к `http://127.0.0.1:8765`, но не управляет жестами.
7. Логи: `adb logcat` (будьте внимательны: в логах могут присутствовать личные данные). Перенос в staging: `adb push update.zip /sdcard/Download/GameAgentStaging/update.zip` **только по явному разрешению**, без запуска.
8. Завершив работу, отключите «Беспроводную отладку» и при необходимости нажмите «Забыть устройство» / «Отозвать разрешения на отладку».

## Этап D. ПК Dashboard и Offload

**Только после подтверждённой установки пакетов на ПК:** Python, `streamlit`, `fastapi`, `uvicorn`.

На телефоне для отладочного сервера понадобятся `fastapi` и `uvicorn`, устанавливаемые **вручную после Y**, например `python -m pip install fastapi uvicorn`.

На телефоне:

```sh
export GAME_REMOTE_TOKEN='длинный_секрет_не_публиковать'
python -m mobile_core.main_mobile --mode MODE_DEBUG --remote --steps 20
```

На ПК:

```powershell
adb forward tcp:8765 tcp:8765
$env:GAME_REMOTE_TOKEN='тот_же_секрет'
streamlit run hub/dashboard.py
```

В Linux: `export GAME_REMOTE_TOKEN='...'` и `streamlit run hub/dashboard.py`.

Для OFFLOAD: запустите сервер на ПК (`GAME_OFFLOAD_TOKEN`, `uvicorn hub.offload_server:create_app --factory --host 127.0.0.1 --port 8888`) и создайте `adb reverse tcp:8888 tcp:8888`. Затем на телефоне выберите `--mode MODE_OFFLOAD --offload-url http://127.0.0.1:8888`; подтвердите отправку скриншотов. При отсутствии загруженной/подключённой модели сервер возвращает 503, а телефон остаётся в локальном fallback.

## Почему Push Code не запускает код сразу

Dashboard предлагает только передачу ZIP в staging. Для этого на телефоне нужен отдельный `--allow-stage-update` и подтверждение. Токен/хэш/размер проверяются, архив не распаковывается и не исполняется. Установка новой версии требует отдельной локальной проверки и одобрения владельца.

## Как удалить

В Android отключите Accessibility в настройках, остановите MediaProjection и удалите Companion. В Termux удалите приватную папку агента (после резервного копирования SQLite при необходимости). На ПК отключите ADB Wi-Fi, отзовите доверие и удалите исходники/установленные только для проекта компоненты по желанию.
