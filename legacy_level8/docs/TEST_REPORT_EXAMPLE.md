# Пример тестового отчёта (синтетический, не факт игровой проверки)

Модуль: `HumanMimicry` · версия: `v0.8.3-replay`.

| Метрика | Пример значения | Вывод |
|---|---:|---|
| Unit Tests | 27/27 | Пройдено (иллюстрация) |
| Покрытие | 91% | Выше порога 80% |
| Средняя задержка | 0,348 с | Внутри проектного диапазона |
| Диагностическая частота смещений | 4,1% | Внутри диапазона 3–5% |
| Диагностическая частота двойных касаний | 2,0% | Тестовая модель, не применяется к игровому вводу |
| Integration | PASS | Проверен Safety Gate |
| Replay | PASS | Без игрового ввода |
| Sandbox | Нет результата | Не тестировалось |
| Shadow | Нет результата | Не тестировалось |
| A/B | Нет результата | Не тестировалось |
| Production | Нет допуска | Заблокировано |

**Вердикт: BLOCK**. Это пример того, как даже успешные технические тесты не разрешают выпуск в игру без длительных проверок.

Известные риски: ложное распознавание CAPTCHA, несовместимые координаты, изменение механики игры, ограниченность статистики A/B, неизвестные правила игры.

Рекомендации: провести 15–30 минут офлайн Sandbox с живым оператором, сравнить решения на Replay, записать реальные метрики батареи/температуры; не делать выводы об отсутствии риска бана по статистике действий.
