# Реальная степень готовности

| Функция | Состояние |
|---|---|
| SQLite / логика задач / касания через контракт / двойная проверка безопасности | Python-код есть, тестируется на mock |
| Termux → Kotlin loopback HTTP | Исходники есть, проверка соединения с устройством не проведена |
| Kotlin MediaProjection + Accessibility | Android Studio scaffold, APK НЕ скомпилирован здесь |
| Уведомление с Panic Stop | Код есть, аппаратный тест не проведён |
| ML Kit OCR | Kotlin-адаптер есть, требуется сборка и проверка качества |
| YOLO TFLite INT8 | Интерфейс адаптера, веса и детектор не включены |
| YAMNet Audio | Интерфейс адаптера, без захвата игрового звука |
| SmolVLM GGUF | Клиент локального OpenAI API, модель/llama.cpp не включены |
| Dashboard | Streamlit реализация, не установлен в этой среде для end-to-end |
| Offload | Таймаут + fallback, тяжёлая VLM на ПК требует подключения реальной модели |
| FAISS Mobile | Не обязателен; SQLite + простой косинусный поиск реализованы |
| Подпись/шифрование логов | HMAC цепочка реализована; Android Keystore и шифрование at rest ещё не реализованы |
| Android Accessibility compliance / игровые ToS | Нужна отдельная проверка владельцем; «анти-бан» не гарантируется |
| Профили предыдущих версий | `legacy_level6/` сохранён; пользовательский L7 не предоставлен |
