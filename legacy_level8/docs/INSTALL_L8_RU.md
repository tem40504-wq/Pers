# Установка и первый безопасный тест Level 8

**Протокол разрешений сохраняется.** Никаких автоустановок и скрытых загрузок. Нужен проверенный Level 7 Mobile+Hub, Python на ПК для тестов, телефон для будущих офлайн-испытаний. Сам ZIP не содержит готового APK.

## Без телефона — проверки кода на ПК

1. Распакуй архив в отдельную папку. Не запускай `.cmd` внутри ZIP.
2. Открой PowerShell в папке с `main_l8.py`.
3. Проверь: `py --version` и `py -m pytest --version`.
4. Если pytest отсутствует — сперва отдельное разрешение оператора (Y/N), затем при согласии его установка по официальной инструкции. Сам Level 8 ничего не устанавливает.
5. Выполни `py -m pytest -q tests/test_level8.py tests/test_mobile.py`.
6. Проверь политику: `py main_l8.py --show-policy`.
7. Проведи демонстрацию, которая **должна завершиться BLOCK** до длительных испытаний: `py main_l8.py --qa-demo`.
8. Не включай онлайн-автоматизацию, пока нет санкционированной площадки и положительного заключения о правилах использования.

Опционально после отдельного разрешения оператора: `py -m pytest -q tests/test_level8.py tests/test_mobile.py --cov=stealth --cov=testing --cov-report=json:coverage.json`. Без установленного `pytest-cov` этот шаг не выполняется.

## Впервые на телефоне — только разрешённая офлайн-игра

1. Сделай резервную копию прогресса и отключи покупки. Выбери локальную офлайн-игру/тестовый экран.
2. Установи и проверь Android Companion Level 7, если он ещё не настроен. Новое APK Level 8 пока не собиралось.
3. Включи локальную запись кадров с ограниченным объёмом и настрой безопасную область (bbox) внутри меню игры, не затрагивающую покупки/удаление.
4. Экран подключённого телефона открыт в игре, и токен Android Companion доступен в Termux через `GAME_BRIDGE_TOKEN`.
5. Запусти безопасные пять наблюдений: `python main_mobile_l8.py --steps 5`.
6. Для офлайн-проверки согласия и dry-run: `python main_mobile_l8.py --offline-qa --steps 30`. Ответь `Y` только после прочтения предупреждения.
7. **Только после оценки dry-run** можно вручную подтвердить реальные жесты: `python main_mobile_l8.py --offline-qa --execute --safe-box 100,200,500,600 --steps 20` (пример безопасной области; пересчитай под экран). Потребуются два подтверждения `Y/N` и включение разрешения Android Companion.
8. Записывай 15–30 минут офлайн-действий в Replay Buffer с несколькими запусками. Накапливай кадры и результаты.
9. Выполни Replay без игрового ввода, затем Shadow и A/B тесты. Если один этап не пройден, оставайся в диагностике.
10. Для реальных нажатий по-прежнему нужны разрешённые навыки, `SecurityCore.validate()`, разрешение Android Companion и активный Dead Man's Switch.

Для проверки Shadow на реальной онлайн-игре нужно отдельно изучить ToS. Даже пассивные автоматизированные инструменты не гарантированно допустимы.

## Остановка и откат

- Экстренно — PANIC STOP в Android-приложении. Он блокирует новые жесты.
- По CAPTCHA/предупреждению агент вызывает `EmergencyStop.panic()` и сохраняет черный ящик.
- При подтверждённой регрессии `AutoRollback` возвращает ранее проверенный снимок конфигурации; это **не** удаляет последствий действий, уже случившихся в игре.

## Рекомендуемая схема версий

`v0.8.3-unit` → `v0.8.3-integration` → `v0.8.3-replay` → `v0.8.3-sandbox` → `v0.8.3-shadow` → `v0.8.3-ab` → `v0.8.3-prod`.
