# Производительность и распределение нагрузки — цели, НЕ бенчмарки

| Работа | Исполнитель | Частота/примерная задержка на Snapdragon 8 Gen 2-class | Особенности |
|---|---|---|---|
| Передача кадра MediaProjection → Termux | Телефон | цель 5–10 FPS; обычно 30–150 мс/кадр при сжатии и IPC | Android может замедлять фоновую работу; Java JPEG дороже GPU pipeline |
| YOLOv8-nano INT8 320x320 | Телефон TFLite GPU/CPU | ориентир 3–15 FPS, возможно ниже | Нужна конвертированная модель + проверка delegate и пред/постпроцессинга |
| Проверка JSON DSL + SafetyCore | Телефон CPU | обычно миллисекунды | Не делать сетевой вызов в быстром цикле |
| ML Kit OCR | Телефон | цель 0.5–2 FPS / 100–700 мс | Зависит от текста, разрешения и устройства |
| YAMNet TFLite | Телефон | окно ~0.96 с; обновление около 1 Гц | Сигнал события зависит от классов, нужен разрешённый звук |
| SmolVLM-256M (GGUF, ARM) | Телефон CPU/GPU | несколько секунд на сложную сцену, сильно зависит от runtime | Только триггер; 1 FPS не гарантируется |
| SQLite + поиск в малой памяти | Телефон | обычно 1–20 мс/запрос для малого объёма | FAISS мобильный wheel может отсутствовать, работает fallback |
| Сложная VLM 7B 4-bit | RTX 5060 Ti 16 GB | ориентир от сотен мс до нескольких секунд | зависит от числа изображений, токенов, квантования и backend |
| DreamerV3/LoRA/GAN | ПК в фоне | не на realtime пути | Обучение требует данных, память VRAM/RAM надо измерять |
| Dashboard | ПК | обновление 0.5–2 Гц | Android сервер отдаёт кадры только по opt-in |

Для Samsung Galaxy S22 Ultra, который ранее использовался для проекта, **не следует применять оценки Snapdragon 8 Gen 2 без проверки чипсета**: он выпускался с другой платформой. Для него производительность и тепловое поведение надо измерить отдельно.

Тепловая адаптация: примерный порог 45°C здесь относится к **датчику батареи**, поскольку `/status` считывает BatteryManager. Реальная защита CPU/GPU должна учитывать Android Thermal API, throttling и ограничивать яркость/кадры через легальные API. Нельзя считать один порог универсально безопасным.

RTX 5060 Ti 16 GB + Ryzen 5 7600X + 32 GB RAM позволяют исследовать локальную VLM и LoRA, но одновременный запуск всех тяжёлых моделей не обещается. При росте RAM свыше ~25 GB сначала измерить память, лишь потом решать о расширении до 64 GB.
