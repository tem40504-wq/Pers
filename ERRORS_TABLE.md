# Ошибки ADB

Причины возможные, не однозначный диагноз.

| Ошибка | Возможная причина | Проверка / решение |
|---|---|---|
| device not found | Потеря транспорта или неверный serial | Проверить devices -l, USB, serial |
| Пустой список | Нет передачи данных, отладки или драйвера | Другой кабель/порт, Диспетчер устройств |
| offline | Транспорт не отвечает | reconnect offline, переподключение |
| unauthorized | Не принят ключ компьютера | Разблокировать и разрешить отладку |
| more than one device | Несколько устройств | --serial / --device |
| Нет IEND | Неполный PNG | VERIFY_ADB_PULL.bat |
| Ошибка CRC | Повреждены данные | Сравнить exec-out и pull |
| Не декодируются пиксели | Повреждён сжатый PNG | Повтор получения, проверить лог |
| Пустой screencap | Команда или поток прерваны | stderr, код завершения, файловый тест |
| Чёрный корректный PNG | Защищённое содержимое или состояние экрана | Проверить обычный экран телефона |
| Permission denied | Недоступный каталог или операция | Проверить разрешения и путь; не применять root автоматически |
| adb.exe не найден | Неверный путь | Указать --adb |
| timeout | Команда/передача не завершилась | USB, конкурирующие ADB-программы, лог |
| server version doesn't match | Разные версии ADB | Один adb.exe, перезапуск сервера |
| Обрыв после сна | Питание USB или драйвер | Проверить конкретный USB-концентратор |

Блокировка экрана не всегда отключает авторизованный ADB. Выключенный экран не всегда означает пустой screencap.
