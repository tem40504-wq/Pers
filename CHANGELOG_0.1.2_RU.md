# GameScreen Voice Android 0.1.2 — исправления

Версия на базе 0.1.1 (Android MVP). **Не относится к Windows GameVoice AI.**

## Критичное

1. **Сборка.** В `app/build.gradle.kts` использовался блок `kotlinOptions { jvmTarget = "17" }`. Начиная с Kotlin 2.2 это **ошибка компиляции** скрипта, а проект на Kotlin 2.3.21 — то есть 0.1.1 не собиралась бы вообще. Заменено на `kotlin { compilerOptions { jvmTarget.set(JvmTarget.JVM_17) } }`.
2. **`BUILD_WINDOWS.ps1` не передавал путь к SDK в Gradle.** Скрипт находил SDK, но если переменная `ANDROID_HOME` не задана (обычная ситуация после установки Android Studio), Gradle падал с «SDK location not found». Теперь при отсутствии создаётся `local.properties` с `sdk.dir`. Также для Windows PowerShell 5.1: отключён прогресс-бар (ускоряет загрузку Gradle в десятки раз), включён TLS 1.2, контрольная сумма скачивается в файл (в PS 5.1 `.Content` мог оказаться массивом байт и проверка падала).
3. **Падение при запуске сервиса.** `OverlayService` при отсутствии разрешения overlay вызывал `stopSelf()` до `startForeground()` — после `startForegroundService()` это приводит к аварийному завершению приложения. Теперь `startForeground()` вызывается первым, а `ForegroundServiceStartNotAllowedException` (Android 12+) перехватывается.
4. **Тёмная тема была нечитаемой.** Compose-экран не рисовал фон: светлый текст полей ввода тёмной схемы (она включена по умолчанию) отображался на белом фоне окна. Добавлен `Surface` с фоном темы; тема окна сменена на тёмную.
5. **Android 15: контент под системными панелями.** При `targetSdk 35` Android 15 принудительно включает edge-to-edge — заголовок уезжал под статус-бар, нижние кнопки — под навигацию, клавиатура перекрывала поля. Добавлены `enableEdgeToEdge()`, `safeDrawingPadding()` и `adjustResize`.

## Перевод и захват текста

6. **Ошибка «залипала».** Из-за `distinctUntilChanged()` после сетевой ошибки тот же текст на экране больше никогда не переводился (и после смены языка тоже). Теперь повтор после ошибки — не чаще раза в 5 с, а ключ дедупликации учитывает языки.
7. **Перевод мог не наступать никогда.** И debounce в Accessibility (260 мс), и `collectLatest` + задержка в pipeline бесконечно откладывались, если игра постоянно меняет UI (таймеры, анимации), а начатый сетевой запрос отменялся новым событием. Теперь у debounce есть верхняя граница ожидания (1 с в сервисе, задержка + 1,5 с в pipeline), запросы выполняются последовательно, а в очереди остаётся только самый свежий текст — устаревший перевод всё так же не может заменить новый.
8. **Фильтр пакета на уровне системы.** Сервис Accessibility теперь через `serviceInfo.packageNames` получает события **только** от выбранного приложения (раньше система будила его на каждое изменение UI любого приложения). Фильтр обновляется сразу при сохранении нового пакета.
9. **Утечка узлов Accessibility на Android 10–12.** Узлы `AccessibilityNodeInfo` теперь возвращаются в пул (`recycle()`; на 13+ это no-op). Регулярное выражение больше не компилируется на каждый узел.
10. **«Тест» всегда обращается к DeepL.** Раньше повторный тест брал результат из кэша (новый/неверный ключ не проверялся), а при запущенном сервисе повторные нажатия игнорировались. Тестовая строка больше не пишется в историю.

## DeepL

11. **Free/Pro определяется автоматически** по ключу: ключи DeepL Free оканчиваются на `:fx`. Переключатель Free/Pro убран — неправильный выбор давал 403.
12. **Исходный язык:** пустое поле (или `AUTO`) — автоопределение DeepL; вариант вида `EN-US` в поле «Из» приводится к `EN` (иначе DeepL отвечал 400).
13. Один автоматический повтор через 1,5 с при 429/5xx/529; понятные сообщения для 413 и 5xx; защита от `null` в ответе.

## Интерфейс

14. **Выбор приложения из списка** установленных (с поиском) вместо ручного ввода имени пакета. Используется `<queries>` для LAUNCHER — без `QUERY_ALL_PACKAGES`.
15. Индикаторы «Accessibility включено/выключено» и «Окно поверх разрешено/нет» обновляются при возврате из системных настроек. При запуске без Accessibility выводится предупреждение.
16. Согласие сохраняется — больше не нужно отмечать его при каждом открытии приложения.
17. Повторное «Запустить» при работающем сервисе применяет размер и прозрачность окна **без перезапуска**. После поворота экрана окно возвращается в пределы экрана.
18. Разрешение на уведомления (Android 13+) запрашивается до запуска сервиса.

## Не изменилось / за рамками
- OCR (этап 0.2), STT/захват звука (0.3), офлайн-перевод, облачные голоса — не реализованы.
- `targetSdk 35` сохранён; для публикации в Google Play после 31.08.2026 нужен 36.

## Проверка

`python tests/static_check.py` — 31 статическая проверка (было 18), все проходят. **APK не собран**: в среде подготовки нет Android SDK и доступа к репозиториям Google/Maven, поэтому компиляция не проверена — возможны мелкие ошибки, которые покажет первая Gradle Sync.
