## С чего начать

- Windows: распаковать архив и запустить `bootstrap.bat` → подключить телефон → `start_agent.bat`.
- Linux: `./bootstrap.sh` → проверить ADB → `./start_agent.sh`.
- `bootstrap.py` расположен внутри пакета `bootstrap/`: `python -m bootstrap.bootstrap --report`.
- По умолчанию запуск без касаний; разрешение на установку или реальные жесты запрашивается отдельно.

**Документация:** `docs/ARCHITECTURE_L9_RU.md`, `docs/INSTALL_WINDOWS_RU.md`, `docs/INSTALL_LINUX_RU.md`, `docs/OFFLINE_RU.md`.

## Что действительно работает

- Проверка ОС, GPU, драйвера NVIDIA, RAM, места, наличия программ.
- Манифест на 61 компонент: 54 позиции с закреплёнными файлами/комплектами и 7 позиций с явными ограничениями.
- Batch Permission Gate с Y/N и журналом, изолированное `venv` по согласию, SHA-256 downloader с возобновлением, офлайн-артефакты, проверки моделей.
- Выбор одного подключённого телефона, ADB-скриншоты и ограниченные жесты.
- Подключение неизменённого PC GameAgent из Level 6, сохранённого внутри Level 8.

## Что НЕ включено в готовый бинарный релиз

- Установщик EXE, собранный и испытанный на Windows; исходники и базовый профиль испытаны на Windows Server 2022.
- Полный проверенный lock-файл GPU wheel, CUDA и конкретных весов моделей. Для базового запуска и тестов Windows уже есть `requirements-windows.lock`; комплекты VLM закреплены, GPU-набор и загрузчики требуют дальнейшей интеграции и аппаратных испытаний.
- Оптимизированный H.264 поток scrcpy 60 FPS; `FastCapture` использует ADB screencap и разрешает подключить дополнительный frame-provider.
- Замер задержек на реальных RTX 5060 Ti и Samsung, подтверждение запуска онлайн-игры.

## Безопасность

Ни один скрипт не ставит пакеты и не скачивает файлы без согласия владельца; скрипты начальной проверки не производят изменений. Системные драйверы устанавливаются отдельно вручную. Онлайн-автоматизация и обход античита не реализованы. Старые исходники сохранены под `legacy_level8/` и могут запускаться своими сценариями при наличии их зависимостей.

## Панель ПК

`start_agent.bat` при авторизованном подключении открывает локальную панель статуса (`127.0.0.1`) с кнопкой PANIC STOP. Это минимальная веб-панель на стандартной библиотеке, **не полноценный видеодашборд XAI**. После завершения тестовых циклов сервер закрывается.

**v9.4:** ASCII/CRLF BAT-запускатор, запуск через launch_agent.py и реальная проверка BAT в Windows CI.
