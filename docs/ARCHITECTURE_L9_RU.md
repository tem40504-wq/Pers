# Уровень 9 — PC-as-Brain + безопасный мастер установки

## Исполнитель и мозг

```
PC (Windows/Linux)                                         Android (без APK)
bootstrap.bat/.sh  ->  check env                            [игра]
      |                 detect GPU/RAM/disk                   ^  | 
      v                                                      |  v
PermissionGate Y/N -> verified artifacts -> self test       ADB USB/Wi-Fi
      |                                                      ^  |
      v                                                      |  v
main_pc_l9.py -> legacy_level8/legacy_level6/GameAgent -> ADBBridge/FastCapture
                       |                 ^
              Perception -> Brain -> ActionExecutor -> Memory
                       |                 ^
              legacy_level8/stealth/testing: preserved as separate code
```

## Что сохранено

`legacy_level8/` — исходники последнего доступного Level 8, включая его мобильную архитектуру и `legacy_level6/game_agent`, который уже управляет Android посредством ADB с ПК. **Ни один модуль внутри legacy не изменён.**

`pc_core/pc_agent_adapter.py` импортирует существующий `GameAgent` из `legacy_level8/legacy_level6`, не подменяя его. `main_pc_l9.py` в режиме по умолчанию создаёт `Settings(dry_run=True)` и делает 5 шагов без касаний. Функции Level 7, которым нужны Android Companion/Termux, остаются в `legacy_level8`, но не запускаются автоматически с ПК.

## Порядок запуска

1. `bootstrap.bat` или `bootstrap.sh`: только диагностика, безопасно повторять.
2. Манифест `bootstrap/dependencies_pc.yaml`: 61 запись, включая 9 добавленных транзитивных зависимостей; 17 подтверждённых файлов для Windows. Дополнительные 44 позиции остаются неподтверждёнными.
3. `BootstrapOrchestrator` проверяет готовность; для недостающего файла необходима **реальная закреплённая SHA-256**.
4. `BatchPermissionGate`: показывает ТОЧНЫЙ список планируемых операций. Только ответ `Y` разрешает операцию; `N` немедленно останавливает без изменений.
5. Файлы скачиваются HTTPS, проверяются SHA-256, копируются или распаковываются только в проект. Системные установщики Windows/Linux запускаются вручную.
6. `PCSelfTest` проверяет Python, свободное место, RAM, GPU, ADB, подключение Android и зарегистрированные модели.
7. `start_agent` запускает только безопасные проверочные циклы; реальные жесты требуют `--execute --offline-approved --safe-zone ...` и второго Y/N.

## Несовпадения исходного технического задания с реальными ограничениями

- Нельзя установить необходимые программы без подтверждения владельца и одновременно заявить «нулевое число кликов». Здесь **один клик запускает мастер**, без скрытых установок.
- Нельзя подставить вымышленные SHA-256 для колёс, ZIP и моделей. В манифесте стоят `null`, пока оператор или разработчик не закрепит SHA-256 конкретного артефакта.
- Нельзя гарантировать CUDA 12.4 при «PyTorch 2.3+» без проверки конкретной пары; PyTorch 2.3.1 официально распространялся с CUDA 11.8/12.1, а CUDA 12.4 поддерживается в 2.4.x.
- `torch.cuda.is_available()` проверяется в изолированном Python, а не объявляется `True` по названию видеокарты.
- `scrcpy` — необязательный просмотр. В этом базовом L9 цикл получает PNG через `adb exec-out screencap -p`. Стриминг 60 FPS и <30 мс пока не реализован и не измерялся.
- Не используется `sendevent`, внедрение в игру, обход античита или скрытые изменения USB/сетевых настроек.
- Утверждения о детекте ADB/бане зависят от условий конкретной игры: гарантированной «безопасной» схемы нет.
- Драйвер NVIDIA, CUDA/cuDNN, Visual C++ и Tesseract устанавливаются вручную с официальных страниц.

## Границы безопасности

- `bootstrap` работает только со строгим манифестом и контролем URL/SHA, без `shell=True`.
- `pc_core/fast_input.py` блокирует все касания по умолчанию, онлайн-ввод и выход за согласованные области.
- Уже отправленный жест нельзя гарантированно отменить при Panic Stop; новые касания блокируются.
- Старые PermissionGate/SecurityCore продолжают использоваться для действий L4–L8. Новый batch gate независим и НЕ отключает их.
- Веса модели из неизвестного источника не загружаются автоматически; загрузка файлов PyTorch pickle не считается безопасной.
