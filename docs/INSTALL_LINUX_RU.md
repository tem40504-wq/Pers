# Установка на Linux (Ubuntu / Debian / Arch)

1. Распаковать архив. Зайти в каталог проекта.
2. Проверить Python: `python3 --version` (нужен >= 3.11); необходимые системные пакеты ставить через свой пакетный менеджер вручную.
3. Запустить `./bootstrap.sh` — только диагностика.
4. Установить ADB через официальные пакеты своего дистрибутива, подключить Android, подтвердить USB-отладку.
5. Проверить `adb devices` (иногда требуется udev-правило; сам агент его не меняет).
6. `python3 -m bootstrap.bootstrap --create-venv` — создаст `.venv` **только после Y**.
7. Подготовить колёса/веса проверенных версий с корректными SHA-256; на Linux не следует без проверки применять Windows CUDA wheel.
8. `python3 -m bootstrap.bootstrap --self-test`; затем `./start_agent.sh`.

Без драйвера NVIDIA останется CPU fallback, но сложная VLM может быть слишком медленной. Никаких обещаний «5–10 раз» без измерений.
