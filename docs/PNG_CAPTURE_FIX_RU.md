# Исправление получения скриншота — v9.3

На пользовательском ПК установка и тесты завершились PASS/Exit code 0. Телефон авторизован, но в первом цикле OpenCV сообщил «PNG input buffer is incomplete». Это ошибка получения/чтения изображения; SKIP отсутствующих дополнительных моделей не является её причиной. Исходная проверка ADB принимала любую последовательность с сигнатурой PNG.

Новый код проверяет все chunk, их CRC, IHDR, IDAT, IEND и декодирование пикселей через Pillow. Неполный или повреждённый файл не попадает в распознавание. Захват повторяется один раз; затем screencap сохраняет PNG во временный файл телефона, а adb pull передаёт его в локальный временный файл. Оба временных файла удаляются после попытки; удаление касается только созданного скриптом уникального пути. Резервный способ не выполняет жесты.

Ошибка цикла теперь передаётся запускающему скрипту: она не выдаётся за успешное завершение. После успешного запуска выводится число выполненных циклов. BAT и Python используют UTF-8 для читаемых русских сообщений.

Для обновления закройте окно агента, распакуйте обновлённый архив, заменив исходники в существующей папке проекта (папка, где находится start_agent.bat). Существующие .venv, tools и downloads не входят в архив и сохраняются. Затем запустите start_agent.bat снова. В норме появится «Наблюдение завершено: 20 успешных циклов; режим без касаний» и Exit code 0.

Если резервный способ также не получает PNG, программа остановится с диагностикой. Тогда требуется проверить разблокировку экрана, USB-кабель и реальное получение screencap на телефоне. Программные regression-тесты не заменяют повторную проверку на Samsung владельца.
