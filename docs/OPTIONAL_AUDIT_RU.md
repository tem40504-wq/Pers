## Исполнение и интеграция

Базовый набор уже успешно испытан на Windows Server 2022 / Python 3.13.14. Для семи дополнительных библиотек подготовлен замкнутый профиль: SciPy, PyYAML, NetworkX, pytest-asyncio, pytesseract, PyAV, FAISS. Повторный Windows-запуск успешно проверил вычисления, работу со звуком, поиск соседей и импорты. Все 85 тестов также прошли. Отчёт: `WINDOWS_SERVER_2022_REPORT.json`; CI: https://github.com/tem40504-wq/Pers/actions/runs/37980083131 . Импорт pytest-asyncio не равен испытанию асинхронных тестов; pytesseract проверяется на обработке изображения, без запуска OCR-движка.

```powershell
py -3.13 run_windows_tests.py --prepare --optional-smoke
```

Другие wheel имеют подтверждённые файлы, но остаются `manual`: не все их транзитивные зависимости закреплены и не выполнены испытания загрузки/инференса. Поле `active_windows_dependencies` показывает совпадения версий, отсутствующие зависимости и конфликты; оно не является lock-файлом всего GPU/VLM-набора. TensorFlow в этом наборе относится к native Windows CPU; GPU не испытан.

У VC Redist и YAMNet независимый хеш издателя не найден: указана официальная версия и собственный SHA-256. Перед запуском VC Redist требуется проверка Authenticode. YAMNet получен архивом с файлом `1.tflite`; хеш внутренней модели указан отдельно. Скачивание не подтверждает готовность аудиоадаптера. Git и Tesseract — установщики, запуск вручную; FFmpeg ZIP закреплён на конкретном autobuild, а не `latest`.

YOLO использует официальные веса COCO, а не модель интерфейса игры. AutoAWQ исключён как устаревший; найденный PyBullet не содержит Windows wheel для CPython 3.13. Драйвер NVIDIA требует модели GPU и версии Windows. CUDA Toolkit и отдельный cuDNN не нужны базовому режиму. Для temporal-lstm и DreamerV3 отсутствуют обученные веса проекта; исходники архитектуры не заменяют checkpoint.

Телефон, Windows 10/11 владельца, RTX/CUDA и полноценная автономная игра остаются неиспытанными.
