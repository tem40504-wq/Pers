# Установка на Windows 10/11

Для v9.2 начните с `WINDOWS_VERIFIED_RU.md`: закреплён профиль Windows x64 / CPython 3.13 и есть `RUN_WINDOWS_TESTS.bat`.

## 1. Подготовка телефона Samsung

1. Настройки → Сведения о телефоне → Сведения о ПО → нажать «Номер сборки» 7 раз.
2. Параметры разработчика → включить «Отладка по USB».
3. Подключить USB-кабель **для передачи данных**, разблокировать экран и подтвердить RSA-доступ своему ПК.
4. После использования при желании выключить отладку и нажать «Отменить разрешения на отладку по USB».

## 2. Подготовка ПК

1. Распаковать ZIP целиком — не запускать `.bat` внутри архиватора.
2. Для закреплённого профиля установить обычный Python 3.13 x64; проверенный установщик 3.13.14 указан в манифесте.
3. Дважды нажать `bootstrap.bat`. Он **не ставит программы и не скачивает модели**, только перечисляет недостающие компоненты.
4. Установить ADB Platform-Tools с https://developer.android.com/tools/releases/platform-tools и добавить папку `platform-tools` в PATH, либо явно задать `ADB_PATH` для старого GameAgent.
5. Проверить командой `adb devices`, статус телефона должен быть `device`, не `unauthorized`.
6. В корне проекта выполнить `py -m bootstrap.bootstrap --create-venv`; появится полное объяснение и запрос `Y/N`. Только после `Y` будет создана папка `.venv`.
7. Для базового запуска выполните `py -3.13 -m bootstrap.bootstrap --profile windows-base --create-venv`. Для испытаний проще запустить `RUN_WINDOWS_TESTS.bat`. Дополнительный GPU/VLM-набор пока не закреплён. Системный Python устанавливается вручную.
8. Выполнить `py -m bootstrap.bootstrap --self-test` и затем `start_agent.bat`. По умолчанию будут пять циклов **без нажатий**.

**Важно:** встроенный `GameAgent` требует минимум NumPy, OpenCV, Pillow и Requests, установленных в запускаемой среде. Если их нет, проверочный режим сообщит об ошибке и прекратит работу — в фоне ничего не поставит.

## RTX 5060 Ti, CUDA и cuDNN

Узнайте фактически установленную версию драйвера через `nvidia-smi`. Выберите PyTorch по таблице официальной страницы https://pytorch.org/get-started/locally/. Часто полный CUDA Toolkit для готового wheel PyTorch не нужен. Версия cuDNN также зависит от выбранного runtime. **Программа не изменяет драйвер автоматически** и не инициирует перезагрузку.

## Первый запуск без риска

```powershell
py main_pc_l9.py --preflight
py main_pc_l9.py --steps 5
```

Для теста в *разрешённой офлайн-среде* реальные касания требуют:

```powershell
py main_pc_l9.py --steps 20 --offline-approved --execute --safe-zone 100,200,600,1000
```

Координаты здесь только пример: нельзя использовать их без проверки реального экрана. Потребуется второе подтверждение `Y`. Программа не гарантирует соблюдение правил какой-либо онлайн-игры.

## ADB через Wi-Fi (опционально)

На телефоне: Параметры разработчика → Беспроводная отладка → сопряжение по коду. На ПК:

```powershell
adb pair IP:PAIRING_PORT
adb connect IP:DEBUG_PORT
adb devices
```

Port сопряжения и порт отладки отличаются. Соединение Wi-Fi не делает автоматизацию незаметной для игрового ПО. При отключении Wi-Fi система не переключает транспорт без явного участия оператора.
