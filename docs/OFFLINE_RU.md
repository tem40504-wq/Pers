# Офлайн-развёртывание

Команда `python -m bootstrap.bootstrap --download-only COMPONENT1 COMPONENT2` скачивает только компоненты с **заранее заполненными** `url` и `sha256`, исключительно после `Y/N`.

Для настоящего офлайн-режима: подготовьте папку `offline_bundle/` с проверенными колёсами, моделями и ZIP из манифеста, а затем на целевом ПК:

```bash
python -m bootstrap.bootstrap --apply COMPONENT1 COMPONENT2 --offline-dir ./offline_bundle --create-venv
```

Архивы с системными EXE (драйвер, CUDA Toolkit, Runtime) необходимо отдельно устанавливать вручную, проверив подпись издателя. Для колёс Python установка выполняется через `pip --no-index --no-deps`: транзитивные зависимости должны быть заранее перечислены и проверены отдельно.

Незаполненный SHA-256 **не обходится** даже при локальном файле. Проверить хеш можно утилитой `certutil -hashfile file SHA256` (Windows) или `sha256sum file` (Linux). Сверяйте хеш с доверенной публикацией производителя, а не просто вычисляйте от неизвестного файла.

**Возобновление:** уже полученные файлы с совпадающими SHA-256 используются повторно. Незавершённые загрузки сохраняются с расширением `.part`. Журнал попыток — `logs/bootstrap_journal.jsonl` (создаётся только во время операций).
