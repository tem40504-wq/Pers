Тестами проверены сохранение корректного имени wheel, отсутствие сетевой установки транзитивных зависимостей, отказ при несовместимой платформе, ненулевой код при частичной установке и отказ Windows runner выдавать Linux за Windows.

Подготовлены run_windows_tests.py и RUN_WINDOWS_TESTS.bat. Они создают отчёт с реальной ОС, журналами, кодами завершения и JUnit. Только реально выполненный успешный запуск может отметить Windows как PASS в новом отчёте. JUnit текущего Linux-запуска приложен: LINUX_JUNIT.xml.

44 дополнительные позиции манифеста требуют подтверждённых артефактов или весов проекта. Контрольные суммы подтверждают целостность файлов, но не готовность автономной игры. Скачанные сторонние EXE/ZIP/wheel не включены в этот компактный архив; закреплённые ссылки и проверка SHA-256 позволяют получить их на Windows.
